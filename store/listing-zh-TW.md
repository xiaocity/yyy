## 完整說明（上限 4000）

```
《羊羊羊之草原牧歌》是一款發生在草坡上的三消解謎。點一張沒被壓住的牌，湊齊三張同樣的就消掉，把盤面清空。

有解是構造出來的，不是碰運氣碰上的

大多數堆疊三消是先隨機鋪一盤，再指望它恰好能過。這一款反過來：先算出一條合法的通關順序，再沿著這條順序鋪花色和特殊牌。所以卡住永遠只是取牌順序的問題，不會遇到從一開始就走不通的盤面。

這帶來一個額外的好處 —— 你輸了，遊戲手上還留著答案。點一下就能在你剛才那一局的盤面上，逐張看完參考解法。

洗牌道具用的是同一套機制：它會對剩下的牌重新求一次解再洗，所以洗出來的一定還是能過的局面。萬一這盤確實洗不出有解排布，它會如實告訴你，並且不扣道具。

四種玩法

· 闖關 —— 五個章節、五十關精心調校的推進，之後一路延伸到兩百關。每十關一個限時 BOSS，每章中段有一個寶箱關當作喘息。
· 每日挑戰 —— 所有玩家同一套題面，每天一換。
· 本週挑戰 —— 每週換一條規則：窄槽、繽紛、迷霧、寬槽、霜凍、爆破。
· 無盡草原 —— 一波接一波，每波之間三選一挑個增益。

六種關卡目標

清空盤面、限定步數內消夠、消掉指定花色、剝掉最上面幾層、把埋在最底下的小羊挖出來、限時內消夠。同一套產生器，六種不同的壓力。

十一種特殊牌

要先消掉旁邊一張才能解凍的冰凍牌；消夠組數才會自動解開的鎖鏈牌；要點兩下的雙層牌；走獨立卡槽的彩虹牌；待在卡槽裡會倒數的炸彈牌；蓋著花色的謎之牌；打到一半才送上來的補給牌；以及四種消掉就給東西的獎勵牌。

一片值得常回來的草原

二十四隻可收集的羊，每隻配一段小故事和一個專屬被動。牧場上四樣可以建的東西。三十六條成就、十二個稱號。四種牌面外觀。

把一局分享給朋友

任何一局都能壓成六位短碼。傳過去，對方就能玩到一模一樣的盤面 —— 短碼還能捎上你的用時，當作一封戰帖。整個過程不經過任何伺服器。

離線，而且不聲張

這款遊戲沒有要求任何網路權限。不上傳任何東西，不蒐集任何資料，也沒有帳號。進度儲存在本機，這也意味著解除安裝或清除資料會一併遺失。

沒有廣告。沒有應用程式內購買。

支援 English、簡體中文、繁體中文。
```

## 说明

- 正文不是 `listing-zh.md` 的机器转换结果。游戏内的繁中走的是字符映射（`index.html`
  的 `TW_PHRASE` + `TW_S`/`TW_T`），那张表只覆盖游戏自己用到的字 —— 商店文案里的
  `广`、`业`、`诚`、`况`、`络` 五个字它一个都没有（这几个字在 `index.html` 里也确实
  一次都没出现，所以不是游戏的 bug）。直接转会得到「無广告」「網络」这种半生不熟的结果。

- 在字形之外还按台湾用语改了词，这些是简体版直译会露馅的地方：

  | 简中版 | 本文件 |
  |---|---|
  | 网络 | 網路 |
  | 服务器 | 伺服器 |
  | 数据 | 資料 |
  | 收集（数据义） | 蒐集 |
  | 卸载 | 解除安裝 |
  | 支持（语言义） | 支援 |
  | 全服 | 所有玩家 |
  | 生成器 | 產生器 |
  | 内购 | 應用程式內購買 |
  | 皮肤 | 外觀 |
  | 战书 | 戰帖 |

- 全篇不要出现「羊了个羊」。那是知名商业游戏，商店文案里提到会撞 Play 的仿冒与知识产权政策。

- 「五十关精心调校的推进，之后延伸到两百关」是诚实的说法：五章 × 十关是调过的正片，
  再往后由生成器按关号插值到第 200 关。

- 离线与零权限这一条是可核对的：清单里一条权限都没有（`aapt2 dump permissions`
  只返回包名），全部资源内嵌在包里。

- 最后两句要跟着实际情况走 —— 一旦接了广告或内购，必须删掉。
