## 平板

清单里那条退出大屏 resizability 的声明已经去掉（见 `android/AndroidManifest.xml`
的注释，里面记了两种清单在平板上的实测对比）。去掉之后横屏铺满、无黑边、
不再弹「此应用未适配大屏」的系统提示框。

平板截图用两台 AVD 拍：

| | 分辨率 | 密度 | 等效 |
|---|---|---|---|
| 7 寸 | 1200×1920 | 320 | 600×960 dp |
| 10 寸 | 1600×2560 | 320 | 800×1280 dp |

**7 寸那套明显更好看。** 应用内容栏封顶 560dp，7 寸屏才 600dp 宽，盘面几乎吃满；
10 寸是 800×1280dp，内容仍按 560dp 排，竖向富余的空间没人用 —— 首页下方约三分之一
是空的，对局页的盘面浮在中间。不是坏了，是没为大屏排版。

要解决得动 `.phone` 的 `width:min(100vw,560px)` 上限和 `computeT()` 的算牌尺寸，
这两处直接决定手机版式，改了必须把手机尺寸重新验一遍。目前的取舍是先按现状上架。

## 局内截图是怎么拍的

`phone-2-gameplay`（限时·消够 25 组）与 `phone-6-rescue`（营救·把被压住的小羊挖出来）
拍的是第 24 与第 23 关：**第 12 关之前根本没有特殊牌**（`LEVELS` 表里 12 条都没写 `sp`），
要十种特殊牌齐全得到第 22 关往后。正常打到那儿要真打二十几关，所以走了这条路：

```sh
store/shot-tools/build_mac.sh store/shot-tools/shot_setup.js   # 把初始化脚本注进 assets/index.html
```

`shot_setup.js` 只做两件事：写初始存档（关卡进度、金币、已见过的特殊牌），然后调用游戏
自己的 `startLevel` 与 `tap`。渲染与玩法逻辑一行没动，画面是真实的游戏画面。
**这个脚本只进本地截图用的 debug APK，正式包不含它。**

两个细节：

- 开局时彩虹牌不一定有露在外面的，空着的彩虹槽说明不了玩法。脚本会反复重开盘面
  （每次都是重新构造的，且都保证有解），直到至少 2 张彩虹牌可点，再点进彩虹槽。
  只放 2 张 —— 满 3 张会自动消除，槽里就又空了。
- 卡槽里那 3 张特意挑花色互不相同的，凑成三连同样会被消掉。

`build_mac.sh` 是 macOS 上的截图专用构建（aapt2 + javac + d8 + apksigner + debug 签名），
和 `android/build.ps1` 不是一回事：那条链子出的是签正式密钥的 AAB，密钥不在这台机器上。

## 几个做的时候踩到的点

**截图必须是 1080×2160 而不是模拟器默认的 1080×2400。** Play 对手机截图的宽高比有上限，
2400 高度是 1:2.22，比上限更极端。用 `adb shell wm size 1080x2160` 把设备设成正好 1:2 再截。

**先试过 1080×1920（9:16），版式会出问题**：首页那个吸底的「开始游戏」按钮会盖住下面两张
模式卡。2:1 的高度刚好够放下全部内容。

**模拟器密度必须是 440，不是默认的 480。** 1080×2160 在 480dpi 下只有 360dp 宽，版式
会整体大一圈，和早先那批截图对不上；440dpi 才是 392.7dp。用 `adb shell wm density 440`
改，重启模拟器也还在。

**软件渲染扛不住这个 WebView。** 用 `-gpu swiftshader_indirect` 起模拟器，游戏会 ANR
（「Sheep Meadow isn't responding」）。换 `-gpu host` 就正常了。

**两套语言各截一份。** 商店主列表用英文（应用名 Sheep Meadow），截图也得是英文的，
否则文案和图对不上。中文那套留给 zh-CN 的本地化列表。英文版式文字更高，
首页底部两张卡会被按钮压到一点 —— 截之前先往下滚一小段。

**图标和功能图里的羊直接取自游戏的 `#sheep` symbol**，配色用 `SHEEP` 表里 `hat` 那五个值，
所以商店素材、桌面图标、游戏内形象三者同源。PIL 不抗锯齿，脚本里一律 4 倍超采样再
LANCZOS 缩回去。

## 文案

已写好，直接复制粘贴即可：

- `listing-en.md` —— 英文（默认列表）。名称 12/30、简短 76/80、完整 2736/4000
- `listing-zh.md` —— 简体中文（zh-CN 本地化列表）。名称 8/30、简短 34/80、完整 897/4000
- `listing-zh-TW.md` —— 繁体中文（zh-TW 本地化列表）。名称 8/30、简短 34/80、完整 908/4000

繁体那份不是简体版的机器转换。游戏内的繁中走字符映射，那张表只覆盖游戏自己用到的字，
商店文案里的 `广`、`业`、`诚`、`况`、`络` 它一个都没有，硬转会得到「無广告」「網络」。
除字形外还按台湾用语换了词（网络→網路、服务器→伺服器、卸载→解除安裝…），
对照表在该文件的「说明」一节。

字数是脚本核过的。英文简短说明原本正好 80/80，一个字符余量都没有，
Play 那边算法只要略有出入就会被拒，已经缩到 76。

## 隐私政策

`privacy-policy.html` —— 中英双语单页，自包含（无外部资源、无脚本），
带暗色模式。丢进 GitHub Pages 之类的静态托管就能得到 Console 里那个必填的 URL。

里面三条事实陈述都核对过，不是凭印象写的：
清单零权限（`aapt2 dump permissions` 只返回包名）、运行期无网络请求
（`fontawesome.com` 只出现在署名注释里）、清空进度的入口名称中英文都对得上。

联系邮箱已填为 `xiaocity@gmail.com`（中英两处）。这个地址会公开显示在商品详情页上，
换成专用支援信箱的话，改 `privacy-policy.html` 里那两处即可。
